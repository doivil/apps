# Interne Web-Apps H. Reich AG

| App | Adresse |
|---|---|
| Absenzen- & Ferienmeldung | https://doivil.github.io/apps/absenzen/ |
| Tagesprogramm (Gantt) | https://doivil.github.io/apps/gantt/ |

Die Apps speichern keine Daten auf GitHub. Meldungen gehen direkt in die Google-Tabellen der Firma.

Das Tagesprogramm liest das Blatt «Baustellen» der Google-Tabelle TAGESPROGRAMM über ein Google-Apps-Script (`gantt/apps-script.gs`), nur lesend und ohne Telefonnummern und E-Mail-Adressen.
